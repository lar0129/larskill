# 中文文档目录

这个文件夹只放中文翻译，供阅读用，不参与插件和 skill 的加载。

两点说明：

- 目录结构镜像仓库原路径，文件名统一加 `.zh.md` 后缀，所以不会被 `skills/` 的发现机制当成真的 skill 文件。
- 原始英文文件才是唯一有效的版本。改了英文，记得回来同步这里。
